# Kelly's Boutique — Website

The public website for Kelly's Boutique: the showroom window with the boutique's
sign, welcome, founder's note, how wardrobe hunts work, the policies in plain
words, and the Chime donation box.

## How it goes live

1. This folder lives in a GitHub repository (github.com) — the "hub" that holds
   the website's files.
2. Render (render.com) connects to that GitHub repository and serves the site
   as a free Static Site, using the settings in `render.yaml`.
3. The result is a real web address (like kellys-boutique.onrender.com) that
   anyone can open in a browser.

## What's in here

- `index.html` — the whole window as one self-contained page.
- `render.yaml` — Render's settings, so setup there is a few taps.

## Note

This is the boutique's public window — a look-in showcase. The full working
store (member accounts, Keeper's Desk, saved profiles) lives privately in
Kelly's Muse app and is not part of this website.
